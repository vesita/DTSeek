## 1. Q1 —— 别名类占重复提及多少（口径 = `evaluate_task` 的 `repeat_mention_acc`）

| 范围 | 重复提及 | 字面同 id | **别名类** | 字面撞车（同字面异 id） |
|---|---|---|---|---|
| seed42 全库 9000 | 26355 | 58.5% | **38.5%** | 3.1% |
| seed42 val 900 | 2582 | 58.7% | **38.4%** | 2.9% |
| seed43 val 900 | 2613 | 58.6% | **38.4%** | 3.0% |

**38.3~38.5% 这个数被独立复现了，两个 seed 都稳。**

但别名类的词面构成是关键信息：**91% 是代词**，不是名字别名。

```
seed42 val 别名类词面 top: 我 454 | 他 132 | 您 112 | 你 108 | 她 96 | 小胡 7 | 小郭 6 ...
```

也就是说「别名类」几乎不是「张伟 → 小张」这种**换名**，而是「张伟 → 他」「A说：我」
这种**代词首次出现**。这决定了语义键要做的其实是**共指消解**，而不是同义改写匹配。

## 2. Q2 —— 冻结基座隐状态上的最近邻，能不能召回同一个人

特征：`doc_memory[b, 提及起始位置]`（另测了 span 均值池化、start+start+1 拼接，结论一致）。

### 2a. 原始余弦：没有任何可用信号

对每个别名重复提及，取它此前所有提及中余弦最近的那个，看是不是同一真值 id：

```
别名类（n=992）  1-NN 召回 = 0.2500 (start) / 0.2752 (mean) / 0.2692 (start2)
prior（随机挑一个更早提及的期望命中率）      = 0.3731
随机特征对照（内容无关的 i.i.d. 高斯）        = 0.4002
```

**1-NN 召回低于「瞎挑」，也低于随机特征对照。** 配对级 AUC（同人物 vs 异人物，样本内配对）
= **0.4534 (start) / 0.4661 (mean) / 0.4814 (start2)** —— 低于 0.5。

按字符距离分桶控制位置邻近混杂后，AUC 仍是 0.462 / 0.465 / 0.497 / 0.533：

```
距离[  0,  8) n= 3169 AUC=0.4621     距离[ 16, 32) n= 6271 AUC=0.4974
距离[  8, 16) n= 4541 AUC=0.4648     距离[32,  ∞) n= 5049 AUC=0.5327
```

即：**原始余弦相似度与「是不是同一个人」无关**（池化后 <0.5 主要是位置邻近 artifact，
控制距离后就是 0.5 附近的噪声）。离线性 1-NN 的 0.774 是另一回事，见 2b。

VQ 码本的忠实模拟（k-means 取码号 → 同码取多数 id）：

```
K=4  覆盖=0.6351 码内纯度=0.1899 覆盖内top1=0.3444 绝对召回=0.2188  （原始特征空间）
K=8  覆盖=0.2258 码内纯度=0.1662 覆盖内top1=0.2857 绝对召回=0.0645
K=64 覆盖=0.0091 码内纯度=0.2593 覆盖内top1=0.3333 绝对召回=0.0030
先验（码内同样本配对的同人物率）= 0.2534
```

在**原始隐状态**上做量化，连「同码=同人」都不成立（纯度 ≤ 先验），几乎没有覆盖。

### 2b. 但「学一个线性度量 W」之后，信号很强 —— 所以 AB 用的是最宽松的版本

先在 train split 上训一个线性度量 W（pair-BCE，175,951 对），再测 val：

```
真 W      : train AUC = 0.8191   val AUC(全部配对)=0.8224  val AUC(表面不同配对)=0.7499
打乱标签 W: train AUC = 0.5195   val AUC(全部配对)=0.5272  val AUC(表面不同配对)=0.4626
原始余弦  :                      val AUC(全部配对)=0.4661
```

**打乱标签对照掉回 chance**，说明 W 学的是共指，不是数据集/模板旁门。
在此度量下，别名类 1-NN 召回 = **0.7742**（「我」0.813 /「他」0.773 /「你」0.769 /「您」0.705 /「她」0.719）。

**这一步改变了判断**：语义信号确实存在，只是**原始余弦取不出来**，得先学一个度量。
所以 AB 我没有用原始余弦（那必然失败），而是用了**最宽松的版本**：冻结基座 + 学出来的 W
+ 离散码本。这也说明下面那个「不成立」的结论是稳的 —— 它是在给足了有利条件之后仍然不成立。

### 2c. 一旦离散化到码本，精度就掉光

同 W 空间里的离散码本（这才是 NDB 能用的形态）：

| 码本 | 别名类覆盖率 | 码内纯度 | 覆盖内 top1 | **别名类绝对召回** |
|---|---|---|---|---|
| 随机码本(LSH) K=1024 | 0.020 | 0.755 | 0.950 | 0.019 |
| 随机码本(LSH) K=16 | 0.354 | 0.523 | 0.558 | 0.198 |
| k-means K=8 | 0.413 | 0.609 | 0.781 | 0.323 |
| 2×k-means K=8 | 0.532 | — | 0.716 | 0.381 |
| **k-means 8 + 4** | **0.827** | — | 0.646 | **0.534** |
| （参照）连续 1-NN | 1.000 | — | — | 0.774 |

覆盖率与「覆盖内 top1」是硬 trade-off：码号粗才有覆盖，粗了就不纯。最好的离散形态
（k-means 8+4）绝对召回 0.534，只有连续 1-NN 的 69%。最终 AB 用的就是这个 `K=(8,4)`。

### 2d. Q3 上界与「要不要训」的判断

- 别名类占重复提及 38.4%，但它只占**指标分母**的 26.7%（字面重复更容易被发射出来）。
- literal-NDB 已经在字面同 id 类上饱和：0.9865 / 0.9892（天花板）。
- literal-NDB 的别名类是 0.4444 / 0.5533 → 别名类 headroom ≈ 0.45~0.55。
- 离散语义键的别名类绝对召回上界 = 0.534。

**上界不「可怜」（远高于 40% 的止损线），所以按纪律跑了 AB。** 但 AB 显示这个上界
translate 不到最终指标上，原因见下。

## 3. 为什么失败（机制，不只是数字）

1. **粗码本把「字面精度」一起扔掉了。** 字面 n-gram 键在字面同 id 类上给出 0.986，
   而 12 个码号的语义键只有 0.860 —— 同一个字面在语义码本里未必落进同一个码号，
   键就不再是「这个字面」的稳定地址。**语义键不是「增强」字面键，它是把字面键替换掉**，
   而字面键在字面类上几乎满分。
2. **覆盖被迫打开 → 首次提及被误判为已覆盖。** 12 个码号意味着表几乎很快就填满，
   `tot > 0` 的覆盖判据几乎恒真；读门控于是被强制打开，新人物被塞进一个已有 id。
   这正是任务背景里「软读把首次提及从 0.999 打到 0.480」的同一条失效路径 ——
   **离散读救不了它，因为失效来自「码号碰撞」而不是「权重软化」**。
   实测 `first_mention_acc` 0.9924 → 0.8707（−0.122）；码本侧也能量到同源证据：
   在别名提及上 82.7% 的位置「此前有提及落在同一个码号里」（覆盖率），
   而其中只有 64.6% 落在同一个人身上 —— 三分之一的覆盖是**假覆盖**。
3. **别名类 91% 是代词，而代词是这个码本最分不开的一类。** 同一个「他」指 A 或指 B，
   在冻结隐状态里差异极小；码本把两个「他」放进同一格的代价，就是这两次提及互相污染。
   实测别名类 acc 从 0.444 掉到 0.359（seed42）—— 它没帮上忙，反而拉低了。

## 5. 我改了哪些测量 / 踩过的坑（供复核）

- **「随机正交阵对照」是空对照**：正交变换逐位保持余弦，两者召回率必然相同
  （实测 0.2500 vs 0.2500）。已换成内容无关的 i.i.d. 随机特征对照。
- **配对探针 acc 0.763 vs 多数类 0.747 看起来「没增益」，但 AUC 是 0.774** ——
  类不平衡下的 acc 会骗人，必须看 AUC/balanced acc。balanced acc = 0.594。
- **打乱标签对照**是判定「W 学的是不是共指」的关键：0.8191 → 0.5195。
- `evaluate_task` 的口径是**未发射的提及不进分母**；按「所有真值提及」数会得到
  0.153 而不是 0.377，差一倍多。所有按类别拆解都复刻了前者。
- 复刻校验必须做：本目录脚本对 base/literal seed42 的主指标与既有日志**逐位一致**。

## 7. 如果还想接着试（我没做，因为已超出「换键」这个假设）

- **别用语义键替换字面键，只用它兜底**：字面键命中就不查语义键。这样字面类的 0.986 不会掉。
  但语义键本身在别名类上拿到的是 0.359（对 0.444 的现状是负贡献），所以还得先解决第 3 条。
- **把「谁在说话」的句法结构显式喂给键**（引语框架的说话人/受话人提及位置），
  而不是指望冻结隐状态自己编码 —— 别名类 91% 是引语里的代词。
- 真正要提升别名类，更像是**让解码头学会引语框架内的指代**（数据/训练侧），
  而不是给检索表换一种键。
