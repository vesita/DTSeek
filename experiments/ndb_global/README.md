# 全局 NDB 对换帧泛化的可行性上界

**结论：上界 ≈ 0（idiom 0.0–0.18%，relation 0.00%）——按纪律停止，不训模型。**
换帧探针的失败是「见过但没学会」，不是「没见过」；全局 NDB 最多只能多救 0–4 个成语、
0 个词对。

独占写范围仅本目录；`src/`、`scripts/`、`training/`、`tests/` 一行未改。

## 口径

- 「训练语料」= `training/train_task_card.py` 默认参数构建出的数据集
  （idiom `--samples 14000`，relation `--samples 14000`），并复刻其
  `random.Random(seed).shuffle` + 前 10% 当验证的切分（seed=42）。
- 「未见词」两种口径都报：
  - **标注覆盖**（NDB 能不能查到这条键）：探针词/词对是否作为**标注正例**出现在训练集里。
    NDB 只回写模型自己发射过的切片，所以只有被标为正例的词才可能让键有值。
  - **字面覆盖**（更宽）：探针词是否在训练集任意文本里出现过（含背景、含作为别的词的子串）。
- 两种口径给出的是**同一个方向的界**：字面覆盖 ⊇ 标注覆盖，所以「字面都见过」直接
  推出「NDB 无从下手」。

**上界 = 0/539 = 0%。** 全局 NDB 在 relation 上没有任何可多救的单元。

## 顺带复现的基线（既有产物，只读）

`checkpoints/cards/relation.pt` + 默认基座，`scripts/eval_probe.py --task relation`
（原文 `raw/relation_probe_baseline.txt`）：

```
539 个单元 × 载体 = 2156 次预测
类别正确率:  94.0%
定位正确率:  53.6%
对完整命中率: 51.2%  (2156 对)
  近义词  92.1%  (1473/1600)
  反义词  99.5%  (553/556)
至少一项判错的单元 493 个
```

说明两点，免得与背景里的数字对不上：

- 背景给的 relation 换帧是「76.5% 定位 / 74.5% 词对完整命中」，与本地
  `checkpoints/cards/relation.pt` 复现出的 53.6% / 51.2% 不是一个产物（本地卡不是
  背景数字的出处）。数字口径差异不影响上界结论 —— 无论定位是 53.6% 还是 76.5%，
  NDB 可多救的单元都是 **0/539**。
- `checkpoints/cards/` 下**没有 idiom 卡**，任何 metrics json 里也没有 idiom，所以
  背景给的 idiom「43.3% 类别 / 15.0% 定位」在本地无法用既有产物复现。按纪律
  （上界 ≈ 0 就不训模型）没有为此新建 idiom 训练跑。

## 判定

1. **上界 ≈ 0。** idiom ≤ 0.18%、relation = 0.00% 的探针单元在训练语料里从未出现。
2. 换帧失败的量级是**几十个百分点**（idiom 类别 43.3% / 定位 15.0%；relation
   定位 53.6% / 完整命中 51.2%，本地产物），而 NDB 能触碰的只有 **0–4 个成语、0 个词对**。
   差距三个数量级。
3. 所以：word→label 的全局 NDB **救不了词表类任务的换帧泛化**。失败是「见过但没学会」
   /「学会了句式没学会词」，不是「没见过」。**不训模型**，本测量即完整交付。
4. 一个诚实的旁注（不改变上面的判定）：本次只算了「未见词」这一条上界 —— 这是本次
   任务的指定判据。若要检验**另一个**假设（「把 NDB 当作跨帧词表检索，去救**已见但换帧
   就错**的词」），那不是这份差集能判定的，且属于本分支被明确禁止的「训模型」动作。
   本目录不做该实验。
