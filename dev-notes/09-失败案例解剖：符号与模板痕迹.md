# 09-一个失败案例的解剖：符号、模板痕迹与看不见的指标

用户实测：

```
DTSeek > 他说：“我不认识你”
```

四个任务给出四种不同的错，而它们**根因各不相同**。这份笔记把每个都钉到证据上。

## 1. 先排除分词器

`“`=id 151、`”`=id 152、`：`=id 150，都在系统词区，逐字符编码无 UNK、无 id 碰撞。
引号没有被吃掉，问题在模型侧。

## 2. 代词卡：触发条件是 `：` 紧接 `“`

隔离实验（每次只改一个符号，其余完全相同）：

| 输入 | 结果 |
|---|---|
| `他说我不认识你` | 第三人称'他'、第二人称'你' —— **我 丢了** |
| `他说，我不认识你` | 第三人称'他'、第二人称'我'、第二人称'你' —— 三个都对 |
| `他说；我不认识你` | 第三人称'他'、第二人称'我'、第二人称'你' —— 三个都对 |
| `他说：我不认识你` | 第三人称'他'、第二人称'你' —— 我 丢了 |
| `他说“我不认识你”` | 第三人称'他'、第二人称'你' —— 我 丢了 |
| **`他说：“我不认识你”`** | **第一人称'他'**、第二人称'你' —— 全错 |

**只有 `：` 与 `“` 同时出现才翻车**，去掉任一个都正常。

从完整概率分布能看到机制——**类别头与指针头不同步**：

```
step1: 第一人称=0.496  第三人称=0.421  第二人称=0.080   -> 指针落在 '他'
```

类别头其实"想"圈第一人称（0.496 最高），指针头却指向 `他`。两个头在这类结构上失配。
而这类「说话动词 + 冒号 + 直接引语」句式在代词卡的合成模板里没有覆盖。

## 3. 看不见的部分：首切片指标

代词卡的验证集实测：

```
【旧指标】只看首切片        : 267/267 = 100.0%
【真实表现】整句完全一致    : 383/400 =  95.8%
            切片级 精确率 98.7%  召回率 96.1%
            多代词句(≥2个)整句一致: 105/120 = 87.5%
```

首切片 100% 而整句 95.8%——**漏掉后面某个代词在这种口径下完全不可见**。
这是第三次撞上同一类问题（前两次：句级 98% vs 词级 43.7%；句级 97.9% vs 换帧 25.4%）。

修法：`evaluate_task` 增加 `exact_match` / `slice_precision` / `slice_recall` 三项整句级指标。

## 4. 归属卡：不是 bug，是它**正确地**套用了模板

同句在归属卡上 `他` → 用户/客户 0.60。对照其他句子：

```
他走了。          -> (未触发) ✓
今天天气不错。     -> (未触发) ✓
我明天再来。       -> (未触发) ✓
请问怎么使用。     -> (未触发) ✓
他说：“我不认识你”  -> 用户/客户'他'    ← 唯独命中模板句式
```

看训练模板就明白了：

```python
DIALOGUE_TEMPLATES = [
    "{speaker}说：这个功能需要再评审一下。",   # ← 同款句式
    ...
]
```

模型学到的是「**X说：** ⇒ X 是说话人标记」，于是把任何代词都当角色。
这是**模板痕迹**：模板本身成了特征。修法不是改模型，是**去模板化 + 加负例**
（`俗话说：`/`书上说：`/`公司说：` 这类有「X说：」结构但不是人物的句子）。

## 5. 情绪卡：对词典外的词强行给答案

`认识` **不在**那 199 词情绪词典里，但：

```
认识     -> 积极/喜悦 '认识'   1.00
不       -> 悲伤/焦虑 '不'     0.94
我没办法  -> 积极/喜悦 '没办'   0.98
我不知道  -> 积极/喜悦 '不知道' 0.54   ← 基本是抛硬币
```

同一个 `不认识`：独立出现→悲伤(0.94)，在完整句里→积极(0.81)，**不稳定**。
根因是模型没有「我不知道」这个出口——词典外的输入被强行塞进四类之一。

## 6. 关系卡：正确地保持沉默 ✓

---

## 三条共性结论

1. **指标口径决定你能看见什么。** 三次假指标都出在"测的东西不是要害"。
   加整句级指标是唯一能让后续每一步变得可验证的动作。
2. **合成模板的句式会变成特征。** `{speaker}说：` 直接成了归属判据；
   `{w}和{w2}` 让模型背句式而不是学关系。模板必须多样 + 必须配负例。
3. **没有拒答出口的模型会在分布外高置信度地胡说。** 情绪卡最严重。

## 7. 用户那句话其实是**共指**问题

`他说：“我不认识你”` 里 `他` 和 `我` 指向**同一个人**（说话人），`你` 是另一个。
代词卡只能给 第三人称/第一人称/第二人称（句法信息），说不了「他和我是一个人」。

所以正解是新增**人物追踪卡**：类别是匿名身份槽（人物1..人物7），id 按段内出场顺序分配，
同一人物的后续提及必须复用同一 id。验收测 `repeat_mention_acc`（重复提及的 id 有没有对上）
与 `cluster_f1`（聚类一致性，对 id 重命名不敏感），而不是 id 本身猜得准不准。
