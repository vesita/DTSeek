# 05-词级探针揭穿句级假象：情绪数据集长尾修复

## 1. 起因

用户实测：

```
DTSeek-Sentiment > 我感觉有点难受
 -> 情绪高亮: 我感觉有点难受
    • Step 1: [4:6] (积极/喜悦, 置信度: 0.4925) '有点难'
```

"难受" 被判成**积极**，且定位截断在 "有点难"。用户判断："应该是欠训练，只在少数情况下表现合理"。

---

## 2. 关键转折：句级验证集一直在骗我们

此前每轮训练都报"情绪任务 97~98% 准确率"，看起来很好。为了定位真实问题，
新建了**词级探针** `scripts/eval_emotion_words.py`：把词典里每个词单独放进中性载体句，
逐个测"类别对不对 + 定位准不准"。

第一次跑就崩了：

```
句级验证集: 98.2%
词级探针:   43.7%   ← 积极 42.1% / 愤怒 76.2% / 悲伤 13.3%
```

### 为什么句级指标会骗人
句级验证集是从**训练语料的同一分布**里抽的。训练语料是真实对话挖掘，
词频服从 **Zipf 分布**：高频词（"难受" 1308 条）反复出现，低频词一条都没有。
验证集抽到的也全是高频词，所以 98% 等于"在自己会的那批词上考自己"。

### 根因量化

```
类别 1(积极): 词典 63 词，训练只出现 41 词；样本量中位数 = 2；22 个词从未出现
              （欢喜、舒心、畅快、痛快、惬意、赞成、赞同、佩服、钦佩、盼望、惊艳、赞叹…）
类别 3(悲伤): 词典 62 词，训练只出现 43 词；中位数 = 3；19 个词从未出现
              （悲痛、心痛、心酸、憋屈、苦闷、消沉、心灰意冷、心塞、堵得慌、揪心、惆怅、忐忑…）
```

模型只会它见过的那几十个词 —— 这正是"只在少数情况下表现合理"。

---

## 3. v3 三条修复

### 3.1 每个词一条下限（合成保底）
`_synthesize_floor` 为词典里**每个词**生成恰好 `per_word_floor` 条样本
（用 45 个载体模板轮转，词在句首/句中/句尾都出现），消灭"从未出现"。

### 3.2 每个词一条上限（真实挖掘封顶）
`_mine_real_capped` 按**首切片词**计数，达到 `per_word_cap` 就跳过该词的句子。
不加封顶时高频词会淹没低频词。

修复前后样本量分布：

| 类别 | 修复前 min/中位/max | 修复后 min/中位/max |
|---|---|---|
| 积极 | 0 / 2 / 2293 | **60 / 129 / 213** |
| 愤怒 | 0 / 28 / 1283 | **62 / 100 / 202** |
| 悲伤 | 0 / 3 / 1308 | **60 / 86 / 236** |

### 3.3 显式否定式
v2 的做法是"检测到否定就把整句丢弃"，结果模型**从没见过否定式**。
v3 把常见否定式直接作为词条收进对应负类：

- `不高兴 / 不开心 / 不快乐 / 不愉快 / 不舒服 / 不痛快 / 不踏实 / 不放心` → 类别 3
- `不满意 / 不喜欢 / 不认可 / 不赞同 / 看不上` → 类别 2

依赖"长词优先匹配"保证 `不高兴` 先于 `高兴` 命中。

### 3.4 无终止标点载体
修完上面三条后，手工测试又暴露一类缺陷：

```
开心      -> 积极 span='开'      ❌ 定位截断
开心。    -> 积极 span='开心'     ✅
心情不错   -> 愤怒 conf=0.511     ❌
心情不错。  -> 积极 conf=0.680     ✅
今天心情不错 -> 积极 conf=0.977    ✅
```

训练集里**所有样本都带终止标点**，而真实聊天输入常常没有句号。
补入 9 个无标点载体（`{e}`、`真的很{e}`、`我现在{e}`、`有点{e}`…）后两者均正常。

## 5. 已知遗留（如实记录）

1. **`痛快` 3/6 载体判错**（被判为悲伤）。原因：它与 `痛苦`（类别 3）共享"痛"字，
   且现代口语中罕见。**这是坏词条而非模型问题**，建议从词典移除或单列。
2. **4 个词各 1/6 载体判错**：`反感 / 无用 / 惶恐 / 无助 / 不高兴` —— 全部出现在
   **孤立裸词**且置信度极低（0.509~0.789）。信息量不足时的不确定，句子级输入不受影响。
3. **句级 94.5% 低于词级 99.3%**：句级测的是真实语料长句（更难），
   词级测的是合成载体（更规整）。两个数不可互相替代。
4. 用户提的**自训练**（用模型给无标注语料打伪标签再训练）尚未实现，
   是下一步扩大真实语料覆盖的自然方向。

## 6. 方法教训（本节最值钱的部分）

**在长尾分布的任务上，同分布验证集的准确率会系统性掩盖"某些类别项完全没学会"。**

- 句级验证回答的是"平均而言好不好"；
- 词级/项级探针回答的是"有没有整项没学会"。
- 两者缺一不可。本项目中前者一直报 98%，后者一跑就暴露 43.7%。

配套的两个工程约束：
- `_validate_carriers` / `_validate_neutral_purity` 采用 **fail-closed 断言**：
  载体模板或中性池一旦混入情绪词，构建数据集时立刻报错，而不是静默污染标签。
  （实际抓到：载体 `"事情已经这样了，{e}也没用。"` 里的"也没用"命中情绪词"没用"；
  中性池 `"请问支持批量导入吗"` 里的"支持"曾被当成积极情绪。）
- 探针自带**已知答案对照**（4 条人工验证过的句子），对照不过就先怀疑探针写错，
  而不是先怀疑模型。
