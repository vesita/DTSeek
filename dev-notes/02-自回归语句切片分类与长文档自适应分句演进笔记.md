# 02-自回归语句切片分类与长文档自适应分句演进笔记

## 1. 架构核心演进：从固定锚点到自回归连续切片发射
在第一期探索中，模型借鉴 YOLO 的固定框回归思想，每个类别强行绑定一个检测头。实测暴露本质局限：无法处理一句话内**同类代词出现多次**（如“我和我们”）或**多代词交错**的复杂自然语言场景。

为此，本项目提出了 **自回归连续切片发射架构（Autoregressive Slice Emission Paradigm）**：
- **输入端编码解耦**：原始文档通过文本编码器（Doc Encoder）仅做一次单向前向计算，缓存记忆特征图（Doc Memory Cache），计算开销恒定；
- **系统动作驱动（`<cont>` / `<eos>`）**：
  - 解码器每步仅吐出一个结构化锚点（包括类别分布、双指针预测的 1-based 闭区间起止索引、以及下一步动作）；
  - 若模型预测动作 token 为 `<cont>`，则自动将该切片的隐状态、类别嵌入与位置编码回填进解码历史序列，驱动模型继续定位下一个实体；
  - 若模型预测动作 token 为 `<eos>`，则宣告该句所有目标切片已全部抽取完毕，自适应终止序列。

## 2. 关键攻坚与踩坑记录

### 坑 1：先验偏差导致的早停（提前 `<eos>` 漏检）
- *现象*：输入包含 3 个代词的长句（如“你好，请问你知道我这句话是什么意思吗”），模型在正确吐出前两个“你”之后提前发出 `<eos>`，漏检后半句的“我”。
- *原因*：真实对话语料中单句包含 $\ge 3$ 个代词的样本天然稀少，模型在步数增多时受到负样本先验主导而倾向于停机；同时缺乏上一步具体切片的显式反馈通道。
- *解决方案*：
  1. **显式切片反馈融合**：在 `RobustARSliceDecoder` 中引入 `feedback_proj`，深度融合上一轮切片的隐状态、类别向量与起止位置，让模型明确感知“已扫描过哪些区域”；
  2. **因果注意力掩码**：在解码序列中引入 Causal Mask，防止未来步骤信息泄漏；
  3. **海量多代词语料挖掘**：开发 `rich_ar_dataset.py`，从 7 大对话语料中挖掘出近 40 万条多代词长短句强化训练，彻底纠正早停偏置。

### 坑 2：长文本感受野超限与硬截断
- *现象*：输入数百字或千字以上的段落时，模型只能定位到前 64 个字符内的代词，后续内容完全“失明”。
- *原因*：小参数量模型（Hidden Dim=128）在训练时锁定了最优短序列长度（64 字符），直接输入长文会被分词器硬截断，且长距离位置编码会产生退化。
- *解决方案*：
  - **程序工程解耦与自适应分句**：开发 `segmenter.py`，按照标点断句将长段落切分为自适应的语义子句（$\le 55$ 字符），保证每个片段天然位于模型最敏锐的感受野内；
  - **全局 1-based 闭区间映射**：在切分时记录全局绝对坐标，推理后将子句内的局部预测无损换算为整篇文章的全局起止位置，实现千字大文章平滑检测。

## 3. 规范定型：纯数字锚点与高亮渲染解耦
- **零文本生成与零幻觉**：模型端仅输出离散的全局起止数字锚点 `[start, end]` 与置信度，不吐出任何原始字词字符串；
- **终端下划线彩色高亮**：由外层渲染函数基于模型输出的 1-based 闭区间直接在原文上执行颜色渲染（第一人称青色、第二人称绿色、第三人称黄色，背景文字保持原样）。
